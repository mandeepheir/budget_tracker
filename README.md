# Budget Tracker

A simple and responsive web application built with HTML, CSS, and JavaScript to track daily expenses and manage personal spending.

## Screenshot

![Budget Tracker Screenshot](screenshots/budget-tracker.png)

## Features

- **Add Expenses:** Record expenses with a name, amount, category, and date.
- **Edit Expenses:** Update existing expense details.
- **Delete Expenses:** Remove expenses with a confirmation prompt.
- **Category Filtering:** Filter expenses by Food, Transport, Entertainment, Utilities, or Other.
- **Automatic Calculations:** View total spending and the number of expenses.
- **Data Persistence:** Save expenses in browser Local Storage.
- **Responsive Design:** Use the application on desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/mandeepheir/budget_tracker.git
```

### 2. Open the Project

Open the downloaded `budget_tracker` folder in Visual Studio Code.

### 3. Run the Application

Open `index.html` in your browser, or use the Live Server extension in VS Code.

No backend server or database setup is required.

## How It Works

The application uses JavaScript to manage expenses and calculate spending totals. Expense data is saved in the browser using `localStorage`, allowing it to persist after refreshing the page in the same browser.
